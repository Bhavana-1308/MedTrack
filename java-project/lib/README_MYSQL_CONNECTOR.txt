Place the MySQL Connector/J JAR file in this directory before compiling and running.

Recommended version:
  mysql-connector-j-8.4.0.jar (or any 8.x / 9.x Connector/J JAR)

Download from:
  https://dev.mysql.com/downloads/connector/j/
  (Select "Platform Independent" -> ZIP/TAR, extract mysql-connector-j-x.x.x.jar into this lib/ folder.)
