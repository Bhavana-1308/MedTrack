# MedTrack – Medicine Reminder and Management System

## Project Overview
MedTrack is a Java-based Medicine Reminder and Management System designed to help users manage their medications efficiently. It allows users to add medicines, schedule reminders, track medication schedules, and maintain medicine-taking history.

## Features
- User Registration and Login
- Add, Update and Delete Medicines
- Schedule Medicine Reminders
- Track Taken and Missed Doses
- View Daily Medication Schedules
- Maintain Medicine History
- User-Friendly Interface

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC

## Java Concepts Used
- Object-Oriented Programming
- Classes and Objects
- Inheritance and Polymorphism
- Encapsulation and Abstraction
- Collections Framework
- Exception Handling
- Multithreading
- JDBC Connectivity

## Database
MySQL is used to store user details, medicine information, reminders, and medication history.

## Project Objective
The main objective of MedTrack is to help users maintain a consistent medication routine through organized medicine management and timely reminders.
